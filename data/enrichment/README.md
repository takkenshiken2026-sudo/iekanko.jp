### 金額カバレッジの向上
全3,058ページのうち**具体的金額あり: 52.1%(1,594) → 59.9%(1,832) に改善（+238件・+7.8ポイント）**。
- 自治体固有の金額を出典ページから抽出: 175件（補聴器・紙おむつ・タクシー・エアコン・出産祝金・敬老祝金・住宅改修・奨学金・予防接種の自己負担・家賃補助 等）
- 国の手当を最新標準額で補完: 35件、妊婦健診を都公費額で補完: 28件
- **金額を数値化できない制度**（住居確保給付＝家賃実費上限、自立支援医療・日常生活用具＝所得別1割負担、配食＝事業者別 等）は無理に数値化せず、`fixed_amount=no`／`amount_text`に負担割合・区分・代表基準額を記載。
- 出典に金額記載がない143件、取得失敗23件（自治体サイトの404/403）は今後の課題。

## status 列の意味
- `verified` … 公式ドメインのページで対象・金額・URLを確認済み。そのまま追加可。
- `needs_amount_check` … 実施は確実だが金額/負担の数値が未取得。追加時に原課/要綱で要確認。
- `candidate` … 主に旧PDF（小笠原2008・青ヶ島2018等）由来。制度の存在発見が主眼、数値は要現在確認。
