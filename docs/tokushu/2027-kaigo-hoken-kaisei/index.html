2027年度の介護保険改正：まず「決まったこと」と「これから」を分ける

3年ごとに見直される介護保険制度の、2027年度（令和9年度）改正が近づいています。報道では「ケアプラン有料化」「2割負担の拡大」といった言葉が目立ちますが、すでに法律で決まったことと、まだ検討が続いていること（先送りされたこと）が混在しています。混同すると不安だけが大きくなるため、現時点で分かっている範囲を切り分けて整理します。

大づかみに言うと、ケアマネジャーの資格更新制の廃止などは「決定」、一方で利用者負担にかかわる「2割負担の対象拡大」や在宅の「ケアプラン有料化」は結論が持ち越し、という状況です（2026年時点）。

決まったこと（2026年6月成立の改正法）

2026年6月に関連する改正法が成立し、次の点が決まったと解説されています。施行は2027年4月1日からとされるものが中心ですが、一部は公布後2年以内の政令で定める日とされ、時期が未定の項目もあります。

  • ケアマネジャーの資格更新制の廃止：定期的な更新研修を前提とした資格更新の仕組みが廃止される方向です。人材確保の観点からの見直しとされています。
  • 登録制の有料老人ホームの創設：いわゆる「住宅型」などの有料老人ホームについて、新たな登録制の類型を設ける見直しです。
  • 施行時期：改正法は2027年4月に一部施行。登録制や新類型のサービスなど一部は、公布後2年以内の政令で定める日とされ、具体的な開始日は今後示されます。

検討が続いていること（先送りされた論点）

家計に直接ひびく論点は、2026年時点では結論が持ち越されています。

  • 2割負担の対象拡大：一定以上の所得がある高齢者の自己負担を1割から2割に広げる案（対象となる年収ラインに複数案）が議論されてきましたが、対象拡大の是非は先送りとなり、次期計画の開始前までに結論を得るとされています。推測ですが、所得の高い層から段階的に広げる方向での議論が続く可能性があります。
  • ケアプランの有料化：在宅でケアマネジャーに居宅サービス計画を作ってもらう「居宅介護支援」全体を有料にする案は、今回も見送りとされています。議論の中心は、登録制有料老人ホーム等の入居者に向けた新しい類型での扱いに限られます。
  • 軽度者サービスの見直し：要介護1・2の一部サービスを市町村の「地域支援事業」へ移す案などが論点として残っています。

「ケアプラン有料化」は全面有料化ではない

「ケアプランが有料になる」という見出しだけが独り歩きしがちですが、在宅でケアマネジャーに計画を立ててもらう場合の自己負担が2027年度から一律に発生する、と読むのは現時点では正確ではありません。在宅の居宅介護支援全体への利用者負担の導入は見送られており、議論は特定の施設類型に限られています。最終的な範囲は、今後の政省令や厚生労働省の公表資料で確認してください。

負担が増える局面で使える、自治体の高齢者支援

保険制度の見直しで自己負担が増える可能性がある局面だからこそ、お住まいの自治体の高齢者向け助成を取りこぼさないことが大切です。これらは介護保険とは別に、市区町村が独自に行っているものです。

自治体の高齢者支援を確認する
  • 介護保険料の減免を自治体で比較する
  • 高齢者の紙おむつ支給・助成を比較する
  • 補聴器購入助成を比較する
  • 緊急通報・見守りを比較する／配食・食事サービスを比較する

家族として今できること

  • 「決定」と「検討中」を分けて受け止める：2割負担の拡大やケアプラン有料化は、報道の見出しだけで判断せず、結論の時期と範囲を確認しましょう。
  • 自己負担の目安を把握する：高額介護サービス費（1か月の自己負担の上限）など、既存の負担軽減の仕組みも確認しておくと安心です。
  • 自治体の助成を確認する：おむつ・補聴器・緊急通報・配食など、介護保険の外にある支援が家計を助けます。上の比較ページで、お住まいの自治体の内容を確認してください。
