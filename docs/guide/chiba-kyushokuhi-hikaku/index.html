2026年4月、国が「公立小学校」の給食費支援を始めた

これまで学校給食費の無償化は、各市町村が独自の判断で行う地域の制度でした。そこに2026年度から国の支援が加わり、公立小学校の給食費が児童1人あたり月額の定額で支援されるようになりました。保護者側の手続きは原則不要で、この部分は全国で負担が軽くなる方向です。

注意したいのは、この国の支援が対象にしているのは「公立小学校」が中心で、中学校は国の統一的な仕組みの外にあるという点です。つまり、中学校まで無料になるかどうかは、これまで通り市町村の独自判断に委ねられています。千葉県内には、国の制度が始まる前から小中学校の給食費を独自に無償化・補助してきた市町村が多くあり、「自分の市はどこまで対象か」を確認する意味が大きいエリアです。

千葉の給食費支援は「3つの型」で見るとわかる

同じ「給食費の支援」でも、県内では主に次の3つの型に分かれます。自分の自治体を調べるときも、この3点を確認すると違いがつかめます。

  • ① 全員無償化（小中とも）：市立の小学校・中学校に通う児童生徒の給食費を、所得や子の数に関係なく全員無償にする型。手続き不要の自治体もあります。
  • ② 多子世帯（第3子以降）のみ：扶養する子が3人以上いる世帯の「上から3番目以降の子」の給食費を無償にする型。千葉県の補助金を活用した自治体に多く見られます。申請が必要なのが一般的です。
  • ③ 補助・減免方式：1食あたりの単価や上限を定めて補助し、実質的に無償にする型。国や県の補助分を差し引いて計算する自治体もあります。

国の小学校支援が始まったことで、何が変わりつつあるか

2026年度に国が公立小学校の給食費を支援し始めたことで、これまで市町村が独自に負担していた「小学校の第3子以降無償化」などの役割が変わりつつあります。四街道市のように、令和8年度から小学校の第3子以降への独自無償化を取りやめ、国の支援に移行する動きもあります。つまり自治体の独自制度は、国の支援と重ならない「中学校」や「多子世帯の上乗せ」へと重心が移っていくとみられます（推測ですが、国の制度設計の方向からはこの流れが続く可能性が高いです）。小学校だけを見て「無料になった」と判断せず、中学校の扱いを必ず確認してください。

「第3子以降」のカウントと申請で気をつけること

  • 子の数え方：多くの自治体が「扶養している子が3人以上」を条件にし、上の子が高校卒業などで扶養から外れると、下の子が繰り上がって対象が変わることがあります。年度ごとに判定される点に注意してください。
  • 申請が必要なことが多い：全員無償の小学校は申請不要でも、第3子以降の無償化や市外の学校に通う場合は、毎年度の申請を求める自治体が一般的です。申請しないと支援が始まりません。
  • 生活保護・就学援助との関係：生活保護や就学援助で給食費の支援をすでに受けている世帯は、重複を避けるため対象外とする自治体があります。

質問回答
千葉県では給食費はどこまで無料ですか？2026年度から国が公立小学校の給食費を支援し始めたため、小学校は負担軽減が進んでいます。中学校は国の統一制度の対象外で、無償化するかは市町村ごとに異なります。千葉県内には小中とも全員無償の市（印西市など）がある一方、第3子以降の多子世帯だけを対象にする市（船橋市・四街道市など）もあります。
「第3子以降だけ無償化」とはどういう意味ですか？扶養している子が3人以上いる世帯で、上から3番目以降の子の給食費を無償にする制度です。子の数え方は扶養している子が基準で、上の子が扶養から外れると対象が変わることがあります。多くは毎年度の申請が必要です。
申請は必要ですか？全員無償の小学校は申請不要の自治体がありますが、第3子以降の無償化や市外の学校に通う場合は、毎年度の申請を求める自治体が一般的です。申請しないと支援が始まらないため、各自治体の案内を確認してください。
国が小学校の給食費を支援するなら、自治体の制度はなくなりますか？自治体の独自制度は、国の支援と重ならない中学校や多子世帯の上乗せへと役割が移りつつあります。四街道市のように令和8年度から小学校の第3子以降への独自無償化を取りやめ、国の支援に移行する例もあります。小学校だけで判断せず、中学校の扱いを確認してください。
引っ越したら手続きは必要ですか？給食費の支援は市町村ごとの制度のため、転入先で改めて対象や申請方法を確認する必要があります。無償化の有無や第3子以降の扱いが変わることがあるため、転入前後に新しい自治体の公式ページで確認してください。
