産後ケア事業は、出産後のお母さんが助産師などから心身のケアや授乳・育児の相談を受けられる市町村の支援です。千葉県内でも多くの市町村が実施していますが、「どの型が使えるか」「1回いくらかかるか」は自治体でかなり違います。宿泊・通所（日帰り）・訪問という3つの型と自己負担の観点で、公式ページの記載をもとに整理しました。お住まいの、あるいは里帰り先の自治体の実際の内容は、末尾の比較ページで確認できます。

産後ケアには「宿泊・通所・訪問」の3つの型がある

産後ケア事業は、国の補助を受けて市町村が実施する仕組みで、提供のしかたに大きく3つの型があります。

  • 宿泊型（短期入所）：助産院や医療機関に泊まって、母体の休息・授乳指導・育児相談などを受けます。
  • 通所型（日帰り・デイケア）：日中に施設へ通ってケアや相談を受けます。母乳ケアに特化したメニューを持つ自治体もあります。
  • 訪問型（アウトリーチ）：助産師などが自宅を訪問し、母体のケアや授乳・育児のサポートを行います。

当サイトが収録した千葉県内の産後ケアでは、宿泊型と訪問型はほぼ全域で実施されている一方で、通所（デイ）型は実施する自治体が限られます。「泊まる」「来てもらう」はどこでも選びやすい一方、「日中だけ通う」という選択肢があるかは住む市町村によって変わる、という形です。里帰り出産で実家のある自治体を頼る場合も、その自治体でどの型が使えるかを先に確認しておくと計画が立てやすくなります。

千葉で確認したい3つのポイント

同じ「産後ケア」でも、次の3点で使い勝手が変わります。

  • ① 使える型：宿泊・通所・訪問のどれが実施されているか。通所（デイ）型の有無は自治体差が出やすい点です。
  • ② 自己負担と所得による減免：宿泊型は1日あたり2,500〜3,000円程度が目安ですが、住民税非課税世帯は半額、生活保護世帯は無料といった所得に応じた減免を設ける自治体があります（佐倉市など）。
  • ③ 対象期間・利用回数：産後2か月まで・4か月まで・1年までなど、型ごとに対象期間が分かれます。利用できる回数にも上限があります。

実例：型と自己負担は自治体でこう違う

公式ページに記載のある3市町を並べると、型の揃い方と料金の考え方の違いがはっきりします。

自治体使える型自己負担（宿泊型の目安）出典
佐倉市宿泊・日帰り・訪問1泊2日5,000円（1日2,500円）。非課税世帯は半額、生活保護世帯は無料佐倉市公式
一宮町宿泊・日帰り・訪問1日2,500円（1日3食とおやつ付き）。日帰りは1回1,800円一宮町公式
九十九里町宿泊・通所デイ・訪問宿泊3,000円／日。通所デイケア2,000円／日、母乳ケア1,200円／日九十九里町公式

3市町とも宿泊型は1日2,500〜3,000円程度に収まりますが、考え方には違いがあります。佐倉市は所得に応じた減免があり、非課税世帯なら宿泊型が半額、生活保護世帯は無料です。負担感は世帯の状況で変わるため、料金表だけでなく減免の有無まで確認しておくと安心です。一宮町のように宿泊型の料金に食事（1日3食とおやつ）が含まれる自治体もあり、同じ金額でも中身が違います。九十九里町のように通所（デイ）型を用意し、母乳ケアなどメニューを分けている自治体もあります。

なお、千葉県内では同じ助産院や医療機関を複数の自治体の住民が利用できる「広域実施」の形もあります（たとえば近隣市町村の助産院が実施施設になっているケース）。利用できる施設と予約方法は自治体ごとに案内されているため、申し込み前に確認してください。

よくある質問

質問回答
千葉県の産後ケアはどんな種類がありますか？泊まってケアを受ける『宿泊型（短期入所）』、日中に通う『通所型（デイケア）』、助産師が自宅へ来る『訪問型』の3つが基本です。当サイトが収録した千葉県内では宿泊型と訪問型はほぼ全域で、通所（デイ）型は実施する自治体が限られます。
産後ケアの料金はいくらですか？宿泊型で1日あたり2,500〜3,000円程度が目安です（自治体により異なります）。佐倉市のように住民税非課税世帯は半額、生活保護世帯は無料といった所得に応じた減免を設ける自治体もあります。日帰り型・訪問型は宿泊型より低い料金設定が一般的です。
里帰り出産でも使えますか？産後ケアは住民票のある市町村の事業として提供されるのが基本です。里帰り先で受けたい場合の取り扱いは自治体で異なるため、お住まいの市町村と里帰り先の双方に事前に確認してください。
いつ申し込めばよいですか？多くの自治体で事前の登録・予約が必要です。出産後は手続きの余裕が少なくなりがちなので、妊娠中のうちに使える型・料金・申し込み方法を確認しておくと安心です。対象期間は型ごとに産後2か月・4か月・1年までなどと分かれます。
