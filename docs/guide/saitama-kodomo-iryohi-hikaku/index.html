埼玉県の子ども医療費助成を自治体で比較｜対象年齢・窓口負担・申請のポイント

埼玉県では、子どもの通院・入院にかかる医療費の多くが「子育て支援医療費（子ども医療費）助成」で助成されます。ただし“どこまで・どうやって無料になるか”は住んでいる市町村で違います。対象年齢・給付のしくみ（窓口無料かどうか）・申請の注意点という観点で、公式ページの記載をもとに整理しました。お住まいの、あるいは引っ越し先候補の自治体の実際の内容は、末尾の比較ページで確認できます。

埼玉県の子ども医療費助成は「県の枠組み＋市町村の上乗せ」でできている

埼玉県の子ども医療費助成は、県が費用の一部を負担する枠組みに、各市町村が独自に上乗せする形で運用されています。国の児童手当のように全国一律ではなく、対象年齢をどこまで広げるか、窓口での支払いをなくすかどうかを、市町村が判断しています。この「上乗せ」の濃淡が、自治体差の正体です。

近年の大きな動きは、対象年齢の引き上げです。当サイトが収録した埼玉県内の子ども医療費助成では、制度を掲載しているすべての市町村で、対象が高校生年代（18歳到達後最初の3月31日＝18歳年度末）まで広がっています。さいたま市・川口市・ふじみ野市などは令和6年（2024年）10月または4月の診療分から、それまでの15歳年度末（中学卒業相当）を18歳年度末へ拡大しました。「中学まで」から「高校卒業まで」へ、という流れが県全体で進んだ格好です。

埼玉で確認したい3つのポイント

同じ「子ども医療費助成」でも、次の3点で手ざわりが変わります。自分の自治体を見るときも、この3点を確認すると違いがつかめます。

  • ① 対象年齢：埼玉県内では高校生年代（18歳年度末）まで対象とする市町村が主流です。一方で所得制限は設けない運用が一般的です。
  • ② 給付のしくみ（窓口無料か）：埼玉県内の医療機関では「現物給付」で窓口の支払いが不要になるのが基本です。ただし、1つの医療機関・1か月あたりの自己負担が21,000円以上になると、いったん窓口で支払って後から申請する扱いの自治体があります（所沢市・三芳町などが公式に明記）。
  • ③ 県外受診・申請：埼玉県外の医療機関にかかったときは、窓口でいったん支払い、後日お住まいの市町村へ申請して払い戻しを受ける「償還払い」になるのが一般的です。

実例：対象は同じ「18歳まで」でも、窓口のしくみに違いがある

対象年齢を18歳年度末まで広げた自治体どうしでも、窓口無料の範囲や高額時の扱いで差が出ます。公式ページに記載のある4市町を並べると、この違いがはっきりします。

4市町とも対象は18歳年度末までで、埼玉県内の医療機関なら原則として窓口の支払いが不要という点は共通です。違いが出やすいのは、1か月の医療費が高額になったときの扱い。所沢市や三芳町のように「1医療機関・1か月21,000円以上は、いったん窓口で支払って後から申請」と明記している自治体があります。入院や大きな治療があった月は、窓口で支払いが生じ、払い戻しの申請が必要になることがある、ということです。これは埼玉県の現物給付のしくみに沿ったもので、同じ県内でも案内の書き方や運用に濃淡があります。

ここで取り上げたのは一例です。他の市町村でも、対象年齢・窓口のしくみ・県外受診時の扱いの組み合わせはさまざまです。
