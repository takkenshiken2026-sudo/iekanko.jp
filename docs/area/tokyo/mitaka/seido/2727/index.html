三鷹市の三鷹市 保育園の保育料無償化（第2子以降・多子世帯軽減）

三鷹市の保育料軽減（多子世帯軽減・第2子以降無償化・副食費助成等）。利用者負担額（保育料）の無償化。令和7年9月利用分以降は第1子を含めすべての児童が無償。幼稚園の預かり保育でも多子世帯の利用料を一部補助

制度の内容

対象者
3～5歳児クラスの全児童、及び0～2歳児クラスは住民税非課税世帯を無償化。令和5年10月からは多子世帯の第2子以降を軽減。令和7年9月利用分以降は第1子を含む全児童無償 出典
支給額・助成額
保育料 全児童無償（令和7年9月利用分以降、第1子含む）／給食費3～5歳児 月6,000円 出典
内容・給付
利用者負担額（保育料）の無償化。令和7年9月利用分以降は第1子を含めすべての児童が無償。幼稚園の預かり保育でも多子世帯の利用料を一部補助 出典
条件
三鷹市民で認可保育施設等を利用する児童。年齢・所得・きょうだい順にかかわらず無償 出典
申請方法
三鷹市公式ページでご確認ください 出典
