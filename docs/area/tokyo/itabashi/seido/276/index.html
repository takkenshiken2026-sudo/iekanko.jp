板橋区の国民健康保険 高額療養費（70歳未満）

板橋区では、70歳未満の国保加入者について、同じ月に同じ医療機関等で21,000円以上の自己負担が複数ある場合など、自己負担限度額を超えた額を高額療養費として支給します。

最終確認日: 2026-07-07 ／ 対象自治体: 板橋区

制度の内容

支給額・助成額
住民税非課税世帯は35,400円など 出典
内容・給付
自己負担限度額を超えた額を支給 出典
条件
21,000円以上の一部負担金を合算 出典

公式ページ: https://www.city.itabashi.tokyo.jp/kenko/kokuho/kokuho/kyufu/1003142.html

この制度について

板橋区に住む方が対象の国民健康保険 高額療養費（70歳未満）（給付）です。同じ制度を東京都の他の自治体と比べたい場合は、 板橋区の制度一覧もあわせてご覧ください。

  • 在宅人工呼吸器使用者非常用電源装置給付事業給付

  • 高齢者補聴器購入費助成助成金
