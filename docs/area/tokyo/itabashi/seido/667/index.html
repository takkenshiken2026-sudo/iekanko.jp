板橋区の負担限度額認定

板橋区では、介護保険施設等の食費・居住費について、要件に応じた負担限度額認定と特例減額措置を案内しています。

最終確認日: 2026-07-08 ／ 対象自治体: 板橋区

制度の内容

条件
世帯構成員数が2人以上 出典
条件
施設利用者負担後の額が80.9万円以下 出典
条件
現金・預貯金等が合計450万円以下 出典

▶ 公式ページ: https://www.city.itabashi.tokyo.jp/kenko/kaigo/futan/1003671.html

この制度について

板橋区に住む方が対象の負担限度額認定（軽減・免除）です。同じ制度を東京都の他の自治体と比べたい場合は、 板橋区の制度一覧もあわせてご覧ください。

板橋区の関連する制度

  • 非課税等世帯エアコン購入費助成助成金
  • 在宅人工呼吸器使用者非常用電源装置給付事業給付
  • 高齢者紙おむつ等の支給給付
  • 高齢者補聴器購入費助成助成金
  • 高齢者の住宅改修費助成事業助成金
  • 国民健康保険 葬祭費給付
