板橋区のがん患者等アピアランスケア支援事業

板橋区では、がんや良性腫瘍の治療に伴う外見の変化に悩む方を対象に、ウィッグや胸部補整具等の購入・レンタル費用の一部を助成します。

最終確認日: 2026-07-07 ／ 対象自治体: 板橋区

制度の内容

対象者
板橋区に住民登録がある方 出典
対象者
がんや良性腫瘍の治療中または治療歴がある方 出典
内容・給付
補整具購入費の一部を助成 出典

公式ページ: https://www.city.itabashi.tokyo.jp/kenko/soudan/1046938/1046941.html

この制度について

板橋区に住む方が対象のがん患者等アピアランスケア支援事業（助成金）です。同じ制度を東京都の他の自治体と比べたい場合は、 板橋区の制度一覧もあわせてご覧ください。

東京都の他自治体と比べる
  • 東京都で「介護用具・福祉用具・寝具乾燥」を自治体比較

板橋区の関連する制度

  • 非課税等世帯エアコン購入費助成助成金
  • 在宅人工呼吸器使用者非常用電源装置給付事業給付
  • 高齢者紙おむつ等の支給給付
  • 高齢者補聴器購入費助成助成金
  • 高齢者の住宅改修費助成事業助成金
  • 国民健康保険 葬祭費給付
