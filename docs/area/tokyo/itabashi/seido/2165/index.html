この制度について

板橋区の板橋区奨学資金の貸付は、区内に1年以上継続居住、高校等に入学・在学、経済的に困難、確実な連帯保証人がいる方を対象とした助成金です。支援内容は、貸付（無利子）。月額上限は公立17,000円・私立29,000円、入学準備金は公立80,000円・私立200,000円。返済は1年据置後最長16年です。支給額・助成額の目安は板橋区奨学資金の貸付：無利子貸付。月額 公立17,000円以内・私立29,000円以内。入学準備金あり（父母の死亡・後遺障がい等は20,000円加算）です。主な条件は、高校・高専・専修学校高等課程に入学許可または在学中の区民で経済的理由により修学困難な者です。

申請方法は板橋区（福祉資金・奨学資金の窓口）へ申請です。
