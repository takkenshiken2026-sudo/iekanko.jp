板橋区の子ども医療費助成

板橋区では、保険診療の範囲内で自己負担となる医療費を助成し、申請した方に乳幼児医療証、子ども医療証または高校生等医療証を発行します。

最終確認日: 2026-07-07 ／ 対象自治体: 板橋区

制度の内容

支給額・助成額
保険診療の範囲内で自己負担となる医療費を助成 出典
内容・給付
子どもの医療費を助成 出典
申請方法
申請者に乳幼児医療証、子ども医療証または高校生等医療証を発行 出典

▶ 公式ページ: https://www.city.itabashi.tokyo.jp/kosodate/teate/iryohi/1004622.html

この制度について

板橋区に住む方が対象の子ども医療費助成（助成金）です。同じ制度を東京都の他の自治体と比べたい場合は、 板橋区の制度一覧もあわせてご覧ください。
