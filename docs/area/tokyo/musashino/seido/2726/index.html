武蔵野市の武蔵野市 保育料の第二子無償化及び一部助成

武蔵野市の保育料軽減（多子世帯軽減・第2子以降無償化・副食費助成等）。第2子以降の利用者負担（保育料）を無償化（令和7年9月分から第1子も無償）。認証・企業主導型は助成上限額引上げ

制度の内容

対象者
認可保育施設に在園する世帯の第2子以降の児童（令和5年10月分より無償）。児童のカウントは年齢問わず保護者と生計同一の子ども。令和7年9月分から第1子も無償 出典
支給額・助成額
認可保育施設 第2子以降の保育料無償（令和5年10月利用分より） 出典
内容・給付
第2子以降の利用者負担（保育料）を無償化（令和7年9月分から第1子も無償）。認証・企業主導型は助成上限額引上げ 出典
条件
所得制限なし。カウントは年齢に関わらず保護者と生計が同一の子（別世帯の生計同一の子、または21歳以上で生計同一の子がいる場合は届出が必要）。開始：第二子は令和5年10月、第一子は令和7年9月 出典
申請方法
生計同一だが別住所等の子がいる場合は届出が必要。子ども育成課 出典

公式ページ: https://www.city.musashino.lg.jp/shussan_kodomo_kyoiku/kodomo_kosodate/hoikuen_yochien_kodomoen/1044647.html
