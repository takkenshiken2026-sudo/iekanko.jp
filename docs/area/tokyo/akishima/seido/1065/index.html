昭島市の特別児童扶養手当

昭島市では、障害のある20歳未満の児童を養育する方に特別児童扶養手当を案内しています。

最終確認日: 2026-07-09 ／ 対象自治体: 昭島市

制度の内容

対象者
20歳未満の障害児 出典
支給額・助成額
1級56,800円、2級37,830円 出典
条件
所得制限等あり 出典

公式ページ: https://www.city.akishima.lg.jp/kosodate/m-kosodate/1003745/1003735/1003740.html

この制度について

昭島市に住む方が対象の特別児童扶養手当（手当）です。同じ制度を東京都の他の自治体と比べたい場合は、 昭島市の制度一覧もあわせてご覧ください。
