この制度について

多摩市の多摩市 就労支援（しごと・くらしサポートステーション）は、仕事や家計の問題など生活の困りごと・不安を抱えた方（家賃が払えない、仕事が見つからない等）を対象としたサービスです。支援内容は、無料相談窓口として、一人ひとりに沿った支援プランを作成し、就労支援等により課題解決に向けて寄り添い支援です。

申請方法は多摩市「しごと・くらしサポートステーション」へ相談です。

金額・対象・申請方法は制度改定で変わることがあります。最新情報は下記の公式ページや多摩市の窓口で必ずご確認ください。
