医療費助成

日野市の心身障害者医療費助成制度（マル障）

日野市では、一定の障害がある方を対象に心身障害者医療費助成制度（マル障）を案内しています。

最終確認日: 2026-07-09 ／ 対象自治体: 日野市

制度の内容

支給額・助成額
課税世帯は医療費の1割負担（外来 月上限18,000円・年上限144,000円／入院を含む世帯 月上限57,600円・多数回該当は44,400円）、住民税非課税世帯は自己負担なし。※東京都の統一基準 出典
条件
所得制限等あり 出典
条件
65歳以上で初めて対象になった方等は対象外 出典
申請方法
身体障害者手帳等と健康保険証が必要 出典

公式ページ: https://www.city.hino.lg.jp/fukushi/nanbyo/service/1027159/1003764.html

この制度について

日野市に住む方が対象の心身障害者医療費助成制度（マル障）（医療費助成）です。同じ制度を東京都の他の自治体と比べたい場合は、 日野市の制度一覧もあわせてご覧ください。
