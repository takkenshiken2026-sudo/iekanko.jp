日野市の国民健康保険 葬祭費（後期高齢者医療 葬祭費）

日野市の国民健康保険・後期高齢者医療の葬祭費支給。国民健康保険の葬祭費5万円を支給（後期高齢者医療は7万円）

制度の内容

対象者
国民健康保険の被保険者が死亡し、葬祭を行った方（喪主等） 出典
支給額・助成額
葬祭費：国民健康保険 5万円／後期高齢者医療 7万円（都内一律、喪主に支給） 出典
内容・給付
国民健康保険の葬祭費5万円を支給（後期高齢者医療は7万円） 出典
条件
国民健康保険または後期高齢者医療の被保険者が死亡したとき、葬祭を行った方（喪主）に支給 出典
申請方法
会葬礼状・領収書等を保険年金課（市役所1階）・七生支所の窓口または郵送で申請 出典
