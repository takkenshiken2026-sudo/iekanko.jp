日野市の高齢者民間住宅家賃助成

日野市では、民間賃貸住宅に住む高齢者のみの世帯を対象に、家賃の一部を助成しています。

最終確認日: 2026-07-09 ／ 対象自治体: 日野市

制度の内容

対象者
65歳以上の高齢者のみの世帯 出典
条件
市内に引き続き3年以上住所がある 出典
条件
家賃を全額自己負担 出典

▶ 公式ページ: https://www.city.hino.lg.jp/fukushi/kourei/1026646.html

この制度について

日野市に住む方が対象の高齢者民間住宅家賃助成（住まい助成）です。同じ制度を東京都の他の自治体と比べたい場合は、 日野市の制度一覧もあわせてご覧ください。
