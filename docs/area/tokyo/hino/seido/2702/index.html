日野市の日野市 認可外保育施設 保護者助成制度

日野市の保育サービス（認可外保育料補助・病児保育・一時預かり等）。東京都の補助を活用した助成。利用施設・サービス、児童のクラス年齢、施設等利用給付認定の有無により補助の有無・金額が異なる。認証保育所等入所児童は保護者補助金（月額上限あり）を交付

制度の内容

対象者
日野市に住民登録があり、対象の認可外保育施設等（認証保育所・家庭福祉員、企業主導型、事業所内、その他認可外）に月極で在籍し利用料を支払っている児童の保護者（一時利用は除く） 出典
支給額・助成額
保育料補助(月額上限)。認証保育所・保育ママ(A)保護者補助金と施設等利用費の合計上限 0-2歳児80,000円／3-5歳児77,000円(施設等利用費37,000円+保護者補助金40,000円)。その他認可外(D)0-2歳児最大67,000円／3-5歳児57,000円。実納付保育料が上限を下回る場合は当該保育料額が上限 出典
内容・給付
東京都の補助を活用した助成。利用施設・サービス、児童のクラス年齢、施設等利用給付認定の有無により補助の有無・金額が異なる。認証保育所等入所児童は保護者補助金（月額上限あり）を交付 出典
条件
認証保育所等を利用する保護者 出典
申請方法
子ども家庭支援課／保育課（公式ページでご確認ください） 出典

公式ページ: https://www.city.hino.lg.jp/kosodate/1028734/1029009/1030038/1029650/index.html
