日野市の高齢・介護で使える制度

高齢者・介護が必要な方が受けられる助成・サービスをまとめています。

日野市・高齢・介護関連の制度 15件

  • 高齢者補聴器購入費助成助成金
  • 高齢者民間住宅家賃助成住まい助成
  • 高齢者自立支援住宅改修給付事業住まい助成
  • 介護保険住宅改修費の支給住まい助成
  • 日野市低所得世帯向けエアコン購入費助成金助成金
  • 令和7年度日野市物価高騰対応食料品等支援事業（ギフトカード配布）給付
  • 心身障害者医療費助成制度（マル障）医療費助成
  • 補装具費の支給給付
  • 日常生活用具費の助成給付
  • 住宅設備改善費の給付住まい助成
  • 都・市の手当（心身障害者（児）福祉手当）手当
  • 特別障害者手当・障害児福祉手当・特別児童扶養手当手当
  • 自動通話録音機の無料貸出給付
  • 帯状疱疹ワクチン予防接種費用助成助成金
  • 在宅ねたきり高齢者等おむつ給付事業サービス
