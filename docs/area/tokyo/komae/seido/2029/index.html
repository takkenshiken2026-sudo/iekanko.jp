狛江市の狛江市地球温暖化対策用設備導入助成

狛江市の住宅向け省エネ・創エネ設備等の導入助成。太陽光発電：1kWあたり2万円（上限8万円）／蓄電池：5万円／エネファーム：対象（額は公式ページでご確認ください）。マンション共用部の上限20万円。都・国補助と併用可

制度の内容

対象者
市内の自ら居住する住宅（分譲マンションの専有部・共用部を含む）に未使用の対象設備を設置する市民等。太陽光発電、蓄電池、家庭用燃料電池（エネファーム）。リース／PPAも対象 出典
内容・給付
太陽光発電：1kWあたり2万円（上限8万円）／蓄電池：5万円／エネファーム：対象（額は公式ページでご確認ください）。マンション共用部の上限20万円。都・国補助と併用可 出典
申請方法
着工前（新築は引渡し前）に交付決定通知が必要。着工30日前までに申請。環境政策課。令和8年度は2026/4/1〜2027/2/26 出典

公式ページ: https://www.city.komae.tokyo.jp/index.cfm/41,127297,313,2006,html
