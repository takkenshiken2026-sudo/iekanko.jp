三宅村の三宅村 生活困窮者自立支援制度・住居確保給付金

町村部では東京都が生活困窮者自立支援制度の実施主体となり、三宅村の生活困窮者にも自立相談支援や住居確保給付金の支給が行われます。

最終確認日: 2026-07-10 ／ 対象自治体: 三宅村

制度の内容

対象者
経済的に困窮し最低限度の生活を維持できなくなるおそれのある方 出典
内容・給付
家賃相当額を有期で給付 出典
内容・給付
家計改善のための転居費用を給付 出典
条件
町村部は東京都が実施主体 出典

公式ページ: https://www.fukushi.metro.tokyo.lg.jp/seikatsu/seikatsukonnkyuu/jiritsu

この制度について

三宅村に住む方が対象の三宅村 生活困窮者自立支援制度・住居確保給付金（住まい助成）です。同じ制度を東京都の他の自治体と比べたい場合は、 三宅村の制度一覧もあわせてご覧ください。

東京都の他自治体と比べる
  • 東京都で「住居確保給付金」を自治体比較
  • 東京都で「生活困窮者自立支援・家計相談」を自治体比較

三宅村の関連する制度

  • 日常生活用具給付給付
  • 介護保険福祉用具購入費及び住宅改修費受領委任払制度住まい助成
  • 三宅村空き家活用対策事業（空き家改修事業補助金）住まい助成
  • 高齢者おむつ代等助成事業助成金
  • 高齢者補聴器購入費助成事業助成金
  • 国民年金保険料の免除・納付猶予軽減・免除
