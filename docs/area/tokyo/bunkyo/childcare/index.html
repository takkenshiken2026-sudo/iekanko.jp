子育て

文京区の子育てで使える制度

児童手当・医療費助成・保育料軽減など、子育て世帯が受けられる支援をまとめています。

文京区・子育て関連の制度 16件・金額が分かるもの合計 130万円（11件）

  • 児童手当手当
  • こども医療費助成助成金
  • 児童育成手当手当
  • 児童扶養手当手当
  • ひとり親家庭等医療費助成助成金
  • 特別児童扶養手当手当
  • 国民健康保険 出産育児一時金給付
  • 小児慢性特定疾病医療費助成制度助成金
  • 認証保育所等保育料補助制度助成金
  • ベビーシッター利用料助成事業助成金
  • ふたごちゃん・みつごちゃん家事・育児サポート利用料助成制度助成金
  • おうち家事・育児サポート事業サービス
  • 子育て支援事業利用料等助成制度サービス
  • こども宅食プロジェクト給付
  • 文京区バースデーサポート事業現金給付
  • 文京区入学支度資金融資あっせん制度助成金
