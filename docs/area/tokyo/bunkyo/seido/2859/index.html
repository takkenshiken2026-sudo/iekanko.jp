文京区の文京区 障害者住宅設備改善費の助成（バリアフリー住宅改修）

文京区の住宅リフォーム・バリアフリー改修・障害者住宅設備改善の助成。居宅生活動作補助用具・住宅設備の改善費を給付。利用者負担は各種目の基準額の1割（特別区民税非課税世帯・生活保護受給世帯は基準額まで無料）。介護保険対象者は介護保険住宅改修が原則優先

制度の内容

対象者
身体障害のある方および難病患者で、日常生活を容易にするために自宅を改造する方 出典
内容・給付
居宅生活動作補助用具・住宅設備の改善費を給付。利用者負担は各種目の基準額の1割（特別区民税非課税世帯・生活保護受給世帯は基準額まで無料）。介護保険対象者は介護保険住宅改修が原則優先 出典
申請方法
事前に相談・申請し支給決定が必要。障害福祉課身体障害者支援係 出典
