制度の内容

対象者
区在住で中学3年生等の子（翌年度に高等学校等へ進学決定）を養育し、児童扶養手当受給世帯または住民税非課税世帯（生活保護受給世帯でない） 出典
支給額・助成額
全部支給：本体 月46,690円／第2子以降加算 月11,030円（一部支給は所得に応じ逓減）。令和7年度額。所得制限あり。※国の制度で全国共通額 出典
内容・給付
給付（高等学校等入学費用の一部）。支給額は公式で確認 出典
申請方法
申請書・合格が分かる書類等を提出。子育て支援課（03-3228-8723） 出典

公式ページ: https://www.city.tokyo-nakano.lg.jp/kosodate/kosodatesite_ohirune/nenreibetsu/kodomo/teate_zyosei/nyuugakushienkin.html
