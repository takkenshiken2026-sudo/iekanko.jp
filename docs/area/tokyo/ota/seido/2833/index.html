大田区の大田区 児童育成手当（育成手当・障害手当）

制度の内容

対象者
育成手当＝区内在住で18歳到達年度末までの児童を扶養し、父母の離婚・死亡、1年以上の遺棄、婚姻によらない出生、拘禁、DV保護命令、生死不明、父母の重度障害等に該当する児童を養育する方。障害手当＝心身に障害のある20歳未満の児童が対象。所得制限あり 出典
支給額・助成額
児童1人につき月13,500円（東京都の制度。支給は年3回〔6月・10月・2月〕、所得制限あり） 出典
内容・給付
育成手当・障害手当がある（東京都制度の一般的な月額は育成手当13,500円/児、障害手当15,500円/児）。正確な支給額は公式ページでご確認ください 出典
申請方法
戸籍謄本・支給事由がわかる公的証明書・通帳等を持参し申請（児童育成担当） 出典

公式ページ: https://www.city.ota.tokyo.jp/seikatsu/kodomo/teate/jidouteate/ikusei.html
