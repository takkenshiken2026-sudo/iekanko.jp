医療費助成

江東区の心身障害者医療費助成（マル障）

江東区に住む重度心身障害者が、医療費の自己負担分の助成を受けられる都の制度（所得制限あり）。

最終確認日: 2026-07-21 ／ 対象自治体: 江東区

制度の内容

対象者
都内在住で身体障害者手帳1・2級（内部障害3級含む）・愛の手帳1・2度・精神障害者保健福祉手帳1級等に該当する方。65歳以上で初めて手帳交付を受けた方・生活保護受給者・所得制限超過者は対象外。 出典
支給額・助成額
保険診療の自己負担分を助成（外来1割・月上限18,000円、入院1割・月57,600円、非課税世帯は負担なし） 出典
条件
本人・世帯に所得制限あり。65歳以上の新規手帳交付者・生活保護受給者は対象外。入院時食事療養費等・保険外は助成対象外。 出典

公式ページ: https://www.city.koto.lg.jp/222015/fukushi/shogaisha/iryo/6757.html

この制度について

江東区に住む方が対象の心身障害者医療費助成（マル障）（医療費助成）です。同じ制度を東京都の他の自治体と比べたい場合は、 江東区の制度一覧もあわせてご覧ください。
