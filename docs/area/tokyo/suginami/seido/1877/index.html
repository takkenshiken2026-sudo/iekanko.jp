杉並区の介護用品の支給等（紙おむつ）

杉並区で在宅の要介護高齢者等に紙おむつの現物支給またはおむつ代助成を行う制度。介護用品支給（月7,000円上限）。

最終確認日: 2026-07-21 ／ 対象自治体: 杉並区

制度の内容

対象者
杉並区内に住所があり介護用品を必要とする在宅高齢者等。 出典
支給額・助成額
月額7,000円を上限に現物支給または入院時おむつ代助成（自己負担は世帯の課税状況で変動） 出典
内容・給付
専用カタログから選んだ介護用品を月額7,000円を上限に毎月自宅へ配送。おむつを持ち込めない病院への入院時はおむつ代を一部助成。 出典

公式ページ: https://www.city.suginami.tokyo.jp/s039/1166.html

この制度について

杉並区に住む方が対象の介護用品の支給等（紙おむつ）（サービス）です。同じ制度を東京都の他の自治体と比べたい場合は、 杉並区の制度一覧もあわせてご覧ください。
