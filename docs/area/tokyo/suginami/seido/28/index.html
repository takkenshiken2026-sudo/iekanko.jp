軽減・免除

杉並区の非自発的失業者の国民健康保険料の減額

非自発的失業者は、離職日の翌日の属する月から翌年度末まで軽減対象になる場合があります。

最終確認日: 2026-07-04 ／ 対象自治体: 杉並区

制度の内容

申請期限
離職日の翌日の属する月から翌年度末まで 出典
申請期限
届出が遅れても遡って適用。ただし再計算できない期間が生じる場合あり。 出典

▶ 公式ページ: https://www.city.suginami.tokyo.jp/s035/1995.html

この制度について

杉並区に住む方が対象の非自発的失業者の国民健康保険料の減額（軽減・免除）です。同じ制度を東京都の他の自治体と比べたい場合は、 杉並区の制度一覧もあわせてご覧ください。
