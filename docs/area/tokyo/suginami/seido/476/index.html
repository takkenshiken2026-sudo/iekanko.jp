杉並区の認証保育所等保育料負担軽減助成金

杉並区では、認証保育所や認可外保育施設等を利用する世帯に、保育料負担軽減助成金を案内しています。

最終確認日: 2026-07-07 ／ 対象自治体: 杉並区

制度の内容

支給額・助成額
認証保育所・認可外保育施設は月額80,000円 出典
支給額・助成額
一時預かり事業等は月額42,000円 出典
内容・給付
保育料負担軽減助成金 出典

公式ページ: https://www.city.suginami.tokyo.jp/s058/shinseisho/19941.html

この制度について

杉並区に住む方が対象の認証保育所等保育料負担軽減助成金（助成金）です。同じ制度を東京都の他の自治体と比べたい場合は、 杉並区の制度一覧もあわせてご覧ください。

東京都の他自治体と比べる
  • 東京都で「保育料軽減・多子軽減」を自治体比較
  • 東京都で「認可外保育料補助」を自治体比較
