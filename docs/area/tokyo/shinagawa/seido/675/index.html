品川区のしあわせ食卓事業

品川区では、ひとり親家庭等を対象に、主食やレトルト食品、缶詰等を宅配する子どもの食の支援を実施しています。

最終確認日: 2026-07-08 ／ 対象自治体: 品川区

制度の内容

支給額・助成額
食品・配送料とも無料 出典
内容・給付
食品を宅配 出典
申請方法
専用申請フォームで申請 出典

公式ページ: https://www.city.shinagawa.tokyo.jp/PC/kodomo/kodomo-kateisoudan/20230111151740.html

この制度について

品川区に住む方が対象のしあわせ食卓事業（給付）です。同じ制度を東京都の他の自治体と比べたい場合は、 品川区の制度一覧もあわせてご覧ください。

品川区の関連する制度

  • 児童手当手当
  • ベビーシッター利用支援事業助成金
  • 麻しん・風しんワクチン任意接種費用の全額助成助成金
  • 子どもすこやか医療費助成助成金
  • 児童育成手当・障害手当手当
  • ひとり親家庭等医療費助成助成金
