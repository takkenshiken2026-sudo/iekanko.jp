中央区の中央区 就学援助制度

中央区の就学援助（学用品費・給食費・修学旅行費等）。学用品費・通学用品費・校外活動費・修学旅行費・給食費・新入学学用品費（入学準備金）・医療費等の一部を援助（品目・支給額は各自治体の要綱による。詳細は公式ページでご確認ください）

制度の内容

対象者
区市町村立小・中学校（義務教育学校等含む）に就学する児童生徒の保護者で、経済的理由により就学費用の負担が困難な世帯（生活保護基準に準じた所得基準等） 出典
内容・給付
学用品費・通学用品費・校外活動費・修学旅行費・給食費・新入学学用品費（入学準備金）・医療費等の一部を援助（品目・支給額は各自治体の要綱による。詳細は公式ページでご確認ください） 出典
申請方法
学校を通じて、または教育委員会の学務課等へ申請。年度当初に学校で申請書を配布する自治体が多い 出典

公式ページ: https://www.city.chuo.lg.jp/a0049/kosodate/gakkoukyouiku/shouchuugakkou/syugakuenzyo.html
