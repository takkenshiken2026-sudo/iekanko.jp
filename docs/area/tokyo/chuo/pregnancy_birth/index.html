妊娠・出産

中央区の妊娠・出産で使える制度

妊娠がわかってから出産までにもらえる給付金・助成と、必要な手続きをまとめています。

中央区・妊娠・出産関連の制度 16件・金額が分かるもの合計 61.5万円（5件）

  • 里帰り出産等に伴う妊産婦健康診査等の費用助成助成金
  • 妊娠高血圧症候群等医療費助成助成金
  • 江戸バス無料乗車支援給付
  • 新生児聴覚検査費用助成助成金
  • 妊娠届・母子健康手帳の交付手続き
  • 中央区外の医療機関での定期予防接種の受け方手続き
  • 産前・産後歯科健康診査サービス
  • 国民健康保険 出産育児一時金給付
  • 妊婦健康診査助成金
  • 里帰り出産等に伴う妊産婦健康診査等の費用助成助成金
  • 未熟児養育医療助成金
  • 産後ケア事業サービス
  • 育児支援ヘルパーサービス
  • 妊婦のための支援給付給付
  • 中央区特定不妊治療医療費助成制度（先進医療）助成金
  • 中央区 出産・子育て応援給付金（伴走型相談支援）助成金
