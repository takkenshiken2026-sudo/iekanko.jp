医療費助成

千代田区のひとり親家庭等の医療費助成

千代田区では、ひとり親家庭等の児童と養育者に対し、医療費の自己負担分を助成する制度を案内しています。

最終確認日: 2026-07-08 ／ 対象自治体: 千代田区

制度の内容

対象者
18歳年度末までの児童等を養育するひとり親家庭等 出典
対象の詳細
障害がある場合は20歳未満まで 出典
条件
生活保護受給中等は対象外 出典

▶ 公式ページ: https://www.city.chiyoda.lg.jp/koho/kosodate/kosodate/hitorioya/teate/hitorioya-i.html

この制度について

千代田区に住む方が対象のひとり親家庭等の医療費助成（医療費助成）です。同じ制度を東京都の他の自治体と比べたい場合は、 千代田区の制度一覧もあわせてご覧ください。

千代田区の関連する制度

  • こども・高校生等医療費助成制度助成金
  • 児童手当手当
  • 中高生世代応援手当手当
  • 国民健康保険 出産育児一時金給付
  • 認可外保育施設等の保育料助成金
  • ベビーシッター利用料金補助助成金
