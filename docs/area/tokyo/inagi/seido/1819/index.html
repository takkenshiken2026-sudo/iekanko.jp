稲城市の帯状疱疹ワクチン予防接種費用助成

稲城市に住む65歳の方等が、帯状疱疹ワクチンを公費助成の自己負担額で接種できる制度（令和7年度から定期接種）。

最終確認日: 2026-07-21 ／ 対象自治体: 稲城市

制度の内容

対象者
接種日に当該自治体に住民登録があり、その年度に65歳になる方（および経過措置として70・75・80・85・90・95・100歳になる方）、60〜64歳で心臓・腎臓・呼吸器等に一定の障害がある方。 出典
内容・給付
定期接種として公費助成（組換えワクチン2回・生ワクチン1回、自己負担額は自治体設定） 出典
条件
定期接種の対象は年度内の特定年齢等に限る（対象外年齢は任意接種）。自己負担額・実施医療機関は自治体により異なる。 出典

公式ページ: https://www.city.inagi.tokyo.jp/kenko/iryou_kenkou/1003044/1003264/1012265.html

この制度について

稲城市に住む方が対象の帯状疱疹ワクチン予防接種費用助成（助成金）です。同じ制度を東京都の他の自治体と比べたい場合は、 稲城市の制度一覧もあわせてご覧ください。

東京都の他自治体と比べる
  • 東京都で「高齢者ワクチン助成(肺炎球菌/帯状疱疹等)」を自治体比較

稲城市の関連する制度

  • 低所得世帯向けエアコン購入費等助成助成金

  • 高齢・障害がある在日外国人対象の福祉給付金手当
  • 介護保険住宅改修費支給住まい助成
  • 介護保険福祉用具購入費支給給付
  • 高齢者住宅「ジョイハウスたまがわ」住まい支援
