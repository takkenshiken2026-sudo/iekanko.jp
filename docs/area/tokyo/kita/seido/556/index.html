北区の安心ママパパヘルパー事業

北区では、産前1か月前から2歳の子どもを育児している家庭を対象に、ベビーシッターや産後ドゥーラが訪問する安心ママパパヘルパー事業を実施しています。

最終確認日: 2026-07-07 ／ 対象自治体: 北区

制度の内容

対象者
産前1か月前から2歳まで 出典
条件
事由を問わず利用可能 出典
条件
保護者と子どもの在宅時のみ 出典

公式ページ: https://www.city.kita.lg.jp/children-edu/childcare/1002833/1002855/1003940.html

この制度について

北区に住む方が対象の安心ママパパヘルパー事業（サービス）です。同じ制度を東京都の他の自治体と比べたい場合は、 北区の制度一覧もあわせてご覧ください。

北区の関連する制度

  • 児童手当手当
  • 子ども医療費助成助成金
  • 児童育成手当手当
  • 児童扶養手当手当
  • 風しん抗体検査・予防接種費用助成助成金
  • 麻しん・風しん任意予防接種助成金
