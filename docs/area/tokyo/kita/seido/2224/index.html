北区の北区親子住まいる応援事業（親との近居・同居）

北区の三世代同居・近居支援（住宅取得・リフォーム・転居費等）。住宅取得に係る登記費用（消費税除く）の一部を助成、上限20万円・1回限り

最終確認日: 2026-07-23 ／ 対象自治体: 北区

制度の内容

対象者
区内に居住する親と近居又は同居するため区内で住宅を新築・購入する子育て世帯・若年夫婦世帯。床面積55㎡以上・新耐震基準適合等。親の住居が賃貸の場合は親が区内に連続5年以上居住等 出典
内容・給付
住宅取得に係る登記費用（消費税除く）の一部を助成、上限20万円・1回限り 出典
申請方法
北区（住宅関連窓口） 出典

公式ページ: https://www.city.kita.lg.jp/living/housing/1009223/1009225.html
