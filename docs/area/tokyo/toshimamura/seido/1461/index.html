利島村の高齢者肺炎球菌予防接種

利島村では、高齢者向けの健康・福祉事業として高齢者肺炎球菌予防接種を案内しています。

最終確認日: 2026-07-10 ／ 対象自治体: 利島村

この制度について

利島村に住む方が対象の高齢者肺炎球菌予防接種（医療費助成）です。同じ制度を東京都の他の自治体と比べたい場合は、 利島村の制度一覧もあわせてご覧ください。

東京都の他自治体と比べる
  • 東京都で「高齢者ワクチン助成(肺炎球菌/帯状疱疹等)」を自治体比較

利島村の関連する制度

  • 高齢者向け事業（シニアカー購入助成・補聴器購入費助成）助成金
  • 心身障害者医療費助成医療費助成
  • 島外医療機関通院交通費等支援事業助成金
  • 難病者等医療通院支援事業助成金
  • 住民健診・事業所健診・がん検診医療費助成
  • 精神科医によるこころの健康相談相談
