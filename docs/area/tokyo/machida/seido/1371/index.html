町田市の母子福祉資金・父子福祉資金

町田市では、母子家庭・父子家庭等を対象に母子及び父子福祉資金の貸付を案内しています。

最終確認日: 2026-07-09 ／ 対象自治体: 町田市

制度の内容

対象者
都内在住で20歳未満の子等を扶養する母子家庭の母・父子家庭の父等 出典
条件
貸付の決定にあたり審査あり 出典
申請方法
余裕をもって事前相談が必要 出典

公式ページ: https://kosodate-machida.tokyo.jp/soshiki/4/5/7/1183.html

この制度について

町田市に住む方が対象の母子福祉資金・父子福祉資金（貸付）です。同じ制度を東京都の他の自治体と比べたい場合は、 町田市の制度一覧もあわせてご覧ください。
