小平市の障害者日常生活用具の給付

小平市では、障害種別・程度等に応じて日常生活用具を給付しています。

最終確認日: 2026-07-09 ／ 対象自治体: 小平市

制度の内容

支給額・助成額
原則1割を自己負担。市民税所得割額46万円以上は対象外（品目別基準額は別ページ） 出典
内容・給付
日常生活用具を給付 出典
支援内容
入浴補助用具、特殊寝台、紙おむつ等 出典
条件
介護保険制度が優先 出典

公式ページ: https://www.city.kodaira.tokyo.jp/kurashi/003/003617.html

この制度について

小平市に住む方が対象の障害者日常生活用具の給付（給付）です。同じ制度を東京都の他の自治体と比べたい場合は、 小平市の制度一覧もあわせてご覧ください。

東京都の他自治体と比べる
  • 東京都で「高齢者紙おむつ支給・助成」を自治体比較
  • 東京都で「障害者日常生活用具・補装具」を自治体比較

小平市の関連する制度

  • 高齢者補聴器購入費助成事業助成金
  • 低所得世帯向けエアコン設置費助成助成金
  • ねたきり高齢者おむつ支給等事業給付
  • 自立支援住宅改修給付住まい助成
  • 自立支援日常生活用具の給付給付
  • 介護保険住宅改修費の支給住まい助成
