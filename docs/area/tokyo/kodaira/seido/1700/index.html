小平市の妊婦のための支援給付

小平市に住む方が、妊娠届出時と出産後に計10万円相当（子1人）の給付を受けられる国の支援。面談とセットで実施。 面談で育児パッケージ1万円あり。

最終確認日: 2026-07-21 ／ 対象自治体: 小平市

制度の内容

支給額・助成額
妊娠時5万円＋出生児1人につき5万円（多胎は人数分） 出典
条件
令和7年4月1日以降に妊娠届出（医師による胎児心拍確認）または出産した住民が対象。伴走型相談支援（面談）とセットで実施。他自治体で同給付を受けていないこと。 出典
申請方法
マタニティサポート面談後に妊婦支援給付5万円＋育児パッケージ1万円を案内。 出典

▶ 公式ページ: https://www.city.kodaira.tokyo.jp/kurashi/118/118381.html

この制度について

小平市に住む方が対象の妊婦のための支援給付（給付）です。同じ制度を東京都の他の自治体と比べたい場合は、 小平市の制度一覧もあわせてご覧ください。
