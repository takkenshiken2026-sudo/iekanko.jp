立川市の立川市特定不妊治療医療費助成金

立川市の不妊・不育治療費等の助成（自治体独自）。特定不妊治療のうち先進医療部分の医療費について、都助成額を差し引いた額を1回上限50,000円まで助成（市独自の上乗せ）

制度の内容

対象者
特定不妊治療の開始日が令和6年4月以降かつ女性の年齢が43歳未満。開始から申請まで法律婚又は事実婚の夫婦で市内に住所、他市区町村から同種助成を受けていない方 出典
内容・給付
特定不妊治療のうち先進医療部分の医療費について、都助成額を差し引いた額を1回上限50,000円まで助成（市独自の上乗せ） 出典
申請方法
立川市へ交付申請書を提出 出典

公式ページ: https://www.city.tachikawa.lg.jp/kenko/iryo/1003161/1020697.html
