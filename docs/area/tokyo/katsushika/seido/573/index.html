葛飾区の多胎児家庭移動支援事業

葛飾区では、0歳、1歳、2歳の多胎児を育てる家庭に、タクシーで使える多胎児家庭応援券を交付します。

最終確認日: 2026-07-07 ／ 対象自治体: 葛飾区

制度の内容

対象者
0歳・1歳・2歳の多胎児を育てる家庭 出典
支給額・助成額
1世帯あたり24,000円分 出典
内容・給付
通院等のタクシー利用に使える「多胎児家庭応援券」（こども商品券）を交付。0〜2歳の多胎児を養育する世帯が対象で児童1人年24000円分。 出典
条件
保健師・助産師による面接が必要 出典

公式ページ: https://www.city.katsushika.lg.jp/kenkou/1000050/1001804/1025660.html

この制度について

葛飾区に住む方が対象の多胎児家庭移動支援事業（助成金）です。同じ制度を東京都の他の自治体と比べたい場合は、 葛飾区の制度一覧もあわせてご覧ください。

東京都の他自治体と比べる

  • 東京都で「タクシー・移送・交通費助成」を自治体比較
