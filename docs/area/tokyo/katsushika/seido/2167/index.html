葛飾区の葛飾区奨学資金貸付

葛飾区の奨学金・進学支援（入学支度金・修学資金等）。貸付。在学中に貸付、卒業後に返済（卒業1年後から毎月口座引落、返済15年以内）。金額は公式で確認

最終確認日: 2026-07-23 ／ 対象自治体: 葛飾区

※この情報は自動収集した暫定データで、内容確認中です。必ず公式ページでご確認ください。

制度の内容

対象者
高等学校・高等専門学校・専修学校の高等課程に入学または在学する向学心のある区内在住者（区内在住かつ60歳未満の連帯保証人が必要） 出典
支給額・助成額
葛飾区奨学資金：貸付。月額 国立・公立高等学校等 18,000円以内。入学準備金あり（翌4月入学予定者のうち希望者、貸付） 出典
内容・給付
貸付。在学中に貸付、卒業後に返済（卒業1年後から毎月口座引落、返済15年以内）。金額は公式で確認 出典
条件
区内在住で高校・高専・専修学校高等課程へ進学希望または高校1・2年在学、経済的に修学困難で向学心のある者（連帯保証人が必要） 出典
申請方法
葛飾区教育委員会事務局教育総務課へ申請 出典

公式ページ: https://www.city.katsushika.lg.jp/kosodate/1000057/1002479/1002750.html
