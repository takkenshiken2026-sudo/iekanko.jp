大島町の町営住宅の入居者募集（家族世帯向）

大島町では、家族世帯向け町営住宅の入居者を随時募集し、使用料は入居者の収入により決定します。

最終確認日: 2026-07-09 ／ 対象自治体: 大島町

制度の内容

支給額・助成額
差木地岳の平団地22300円～43800円／差木地クダッチ団地20800円～40800円／筆島団地26500円～52100円／波浮港山口第三団地21100円～41500円（収入により決定） 出典
内容・給付
町営住宅（2LDK、59.3～85.0㎡、月額22,300～52,100円）に入居できる。町内に1年以上居住・勤務し同居親族がある収入基準内の世帯が対象、計8戸を随時募集。 出典
条件
真に住宅に困窮している方 出典
条件
所得の合計が収入基準以内 出典
引っ越し関連
大島町では家族世帯向け町営住宅があり、収入に応じた使用料で入居できる場合がある。 出典

公式ページ: https://www.town.oshima.tokyo.jp/soshiki/kensetsu/choei-jutaku-kazoku20250204.html

この制度について

大島町に住む方が対象の町営住宅の入居者募集（家族世帯向）（住まい支援）です。同じ制度を東京都の他の自治体と比べたい場合は、 大島町の制度一覧もあわせてご覧ください。

大島町の関連する制度

  • 大島町高齢者自立支援住宅改修給付事業住まい助成
  • 自立支援日常生活用具給付事業給付
  • 重度心身障害者（児）日常生活用具給付等事業給付
  • 大島町 定住促進のための奨学金返還支援補助金助成金
  • 大島町 移住者向け町営住宅（目的外使用）助成金
