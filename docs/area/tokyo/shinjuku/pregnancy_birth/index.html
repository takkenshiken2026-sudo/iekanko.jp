新宿区の妊娠・出産で使える制度

妊娠がわかってから出産までにもらえる給付金・助成と、必要な手続きをまとめています。

新宿区・妊娠・出産関連の制度 8件

  • 児童手当手当
  • 国民健康保険 出産育児一時金給付
  • 大人の風しん麻しん抗体検査と予防接種の費用助成助成金
  • 産後ケア事業助成金
  • 産前産後支援事業サービス
  • 多胎児家庭への移動支援事業サービス
  • 妊婦健康診査費用助成助成金
  • 妊婦のための支援給付給付
