新宿区の子育てで使える制度

児童手当・医療費助成・保育料軽減など、子育て世帯が受けられる支援をまとめています。

新宿区・子育て関連の制度 12件

  • 児童手当手当
  • 子ども医療費助成助成金
  • 児童育成手当手当
  • 児童扶養手当手当
  • ひとり親家庭等医療費助成制度助成金
  • 高校生等医療費助成（マル青）助成金
  • 認証保育所・認可外保育施設の保育料助成助成金
  • 国民健康保険 出産育児一時金給付
  • ベビーシッター利用支援事業（一時預かり利用支援）助成金
  • 私立幼稚園等の入園料・保育料等補助金申請助成金
  • 産前産後支援事業サービス
  • 多胎児家庭への移動支援事業サービス
