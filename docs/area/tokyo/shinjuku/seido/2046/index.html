新宿区の新宿区低所得世帯・生活保護受給世帯に対するエアコン購入費助成

新宿区の高齢者・低所得世帯等向けエアコン設置費助成（熱中症予防）。エアコン購入にかかる費用を助成。上限額は公式ページでご確認ください

制度の内容

対象者
冷房使用可能なエアコンを1台も保有していない世帯等で、住民税非課税／均等割のみ課税／児童扶養手当受給／生活保護受給のいずれか 出典
支給額・助成額
全部支給：本体 月46,690円／第2子以降加算 月11,030円（一部支給は所得に応じ逓減）。令和7年度額。所得制限あり。※国の制度で全国共通額 出典
内容・給付
エアコン購入にかかる費用を助成。上限額は公式ページでご確認ください 出典
申請方法
令和8年5月以降コールセンター開設予定。福祉部 出典

公式ページ: https://www.city.shinjuku.lg.jp/fukushi/fukushi01_000001_00037.html
