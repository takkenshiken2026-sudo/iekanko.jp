制度の内容

対象者
村内に居住し住民基本台帳に登録されている方で、本人および同一世帯員が村税等を滞納していないこと、かつ都の『東京ゼロエミポイント』の付与を受けている方 出典
内容・給付
CO2排出量の多いエアコン・冷蔵庫の省エネ家電への買換えに対し、都事業（東京ゼロエミポイント）の付与ポイントと同額（1ポイント=1円換算）を村が上乗せ補助 出典
申請方法
東京ゼロエミポイント付与の通知から60日以内に、補助金交付申請書と都事業のポイント交付決定通知書の写しを環境課へ提出 出典

公式ページ: https://www.vill.ogasawara.tokyo.jp/kankyo/zerocarbon/syoenekaden/
