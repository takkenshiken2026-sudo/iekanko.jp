この制度について

小笠原村の小笠原村 高齢者運賃割引（おがさわら丸 島外受診）は、疾患の治療目的で内地の医療機関に入院・通院する高齢者、および同行する介護者を対象とした助成金です。支援内容は、定期船「おがさわら丸」の運賃割引（村民課で証明書の交付を受けて利用）。割引額は公式ページでご確認くださいです。

申請方法は村民課 住民係／母島支所 庶務係です。
