小笠原村の医療費助成

小笠原村では、乳幼児、小中学生、高校生等、ひとり親家庭等を対象に医療費助成を行っています。

最終確認日: 2026-07-08 ／ 対象自治体: 小笠原村

制度の内容

対象者
小学生・中学生など 出典
内容・給付
保険診療の自己負担分を全額助成 出典
申請期限
原則申請した月から 出典
引っ越し関連
小笠原村では乳幼児・小中学生・高校生等・ひとり親家庭等の医療費助成があり、転入後15日以内申請の特例がある。 出典

▶ 公式ページ: https://www.vill.ogasawara.tokyo.jp/sonmin/iryouhijosei/

この制度について

小笠原村に住む方が対象の医療費助成（医療費助成）です。同じ制度を東京都の他の自治体と比べたい場合は、 小笠原村の制度一覧もあわせてご覧ください。
