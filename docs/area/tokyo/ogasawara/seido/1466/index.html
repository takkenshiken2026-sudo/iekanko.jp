小笠原村の小笠原村 生活困窮者自立支援制度・住居確保給付金

町村部では東京都が生活困窮者自立支援制度の実施主体となり、小笠原村の生活困窮者にも自立相談支援や住居確保給付金が行われます。

最終確認日: 2026-07-10 ／ 対象自治体: 小笠原村

制度の内容

対象者
経済的に困窮し最低限度の生活を維持できなくなるおそれのある方 出典
内容・給付
家賃相当額を有期で給付 出典
内容・給付
家計改善のための転居費用を給付 出典
条件
町村部は東京都が実施主体 出典

公式ページ: https://www.fukushi.metro.tokyo.lg.jp/seikatsu/seikatsukonnkyuu/jiritsu

この制度について

小笠原村に住む方が対象の小笠原村 生活困窮者自立支援制度・住居確保給付金（住まい助成）です。同じ制度を東京都の他の自治体と比べたい場合は、 小笠原村の制度一覧もあわせてご覧ください。

東京都の他自治体と比べる
  • 東京都で「住居確保給付金」を自治体比較
  • 東京都で「生活困窮者自立支援・家計相談」を自治体比較
