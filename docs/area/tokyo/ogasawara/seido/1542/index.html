小笠原村のほがらかサービス事業

小笠原村では、65歳以上で日常生活上の軽度な援助が必要な方に、草むしり、大きな荷物の移動、大掃除、台風養生などの生活支援を行っています。

最終確認日: 2026-07-10 ／ 対象自治体: 小笠原村

制度の内容

対象者
65歳以上で要支援認定等を受け、日常生活上軽度な援助が必要な方 出典
内容・給付
草むしり、大きな荷物の移動、大掃除、台風養生など 出典
申請方法
利用申請書で申請。利用期間は最長で申請年度の3月末日まで 出典

▶ 公式ページ: https://www.vill.ogasawara.tokyo.jp/reiki_int/reiki_honbun/g164RG00000252.html

この制度について

小笠原村に住む方が対象のほがらかサービス事業（サービス）です。同じ制度を東京都の他の自治体と比べたい場合は、 小笠原村の制度一覧もあわせてご覧ください。
