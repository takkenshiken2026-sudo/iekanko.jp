台東区の年金生活者支援給付金制度

台東区では、公的年金等の収入額とその他所得の合計が一定基準以下の年金受給者向けに、年金生活者支援給付金制度を案内しています。

最終確認日: 2026-07-07 ／ 対象自治体: 台東区

制度の内容

対象者
一定基準以下の年金受給者 出典
支給額・助成額
令和8年度の老齢給付金は月額5,620円を基準 出典
申請方法
手続きは日本年金機構が実施 出典

公式ページ: https://www.city.taito.lg.jp/kurashi/zeikin/kokuminnenkin/shienkyufukin.html

この制度について

台東区に住む方が対象の年金生活者支援給付金制度（給付）です。同じ制度を東京都の他の自治体と比べたい場合は、 台東区の制度一覧もあわせてご覧ください。

台東区の関連する制度

  • 国民年金 産前産後期間の保険料免除軽減・免除
  • 国民年金保険料の免除・納付猶予制度軽減・免除
  • 紙おむつの支給給付
  • 後期高齢者医療 葬祭費給付
  • 聞こえの改善機器購入費助成助成金
  • 高齢者住宅改修給付助成金
