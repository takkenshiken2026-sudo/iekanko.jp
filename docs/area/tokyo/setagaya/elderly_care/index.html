高齢・介護

世田谷区の高齢・介護で使える制度

高齢者・介護が必要な方が受けられる助成・サービスをまとめています。

世田谷区・高齢・介護関連の制度 19件・金額が分かるもの合計 368万円（6件）

  • 要介護・要支援認定申請からサービスの利用まで手続き
  • 要介護・要支援認定申請様式手続き
  • 高齢者補聴器購入費助成助成金
  • 紙おむつの支給・助成給付
  • がん先進医療費利子補給制度助成金
  • がん患者等アピアランスケア費用助成事業助成金
  • 国民健康保険 限度額適用認定証の交付（69歳まで）手続き
  • 国民健康保険 高額療養費の支給給付
  • 介護保険 負担限度額認定証軽減・免除
  • 福祉タクシー券の交付給付
  • 心身障害者福祉手当等手当
  • 心身障害者医療費助成（マル障）医療費助成
  • 帯状疱疹ワクチン予防接種費用助成助成金
  • 慶祝品現金給付
  • 低所得世帯エアコン購入費等助成助成金
  • 世田谷区 介護保険料の減免・軽減助成金
  • 世田谷区救急通報システム「愛のペンダント」助成金
  • 世田谷区 高齢者住宅改修費助成助成金
  • 世田谷区 障害者（児）日常生活用具の給付・補装具の交付助成金
