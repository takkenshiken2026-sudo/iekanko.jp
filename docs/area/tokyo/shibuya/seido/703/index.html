渋谷区の福祉タクシー券の交付

渋谷区では、歩行困難な重度心身障がい者の日常生活の利便のため、福祉タクシー券を交付します。

最終確認日: 2026-07-08 ／ 対象自治体: 渋谷区

制度の内容

対象者
歩行困難な重度心身障がい者等 出典
支給額・助成額
月300円券9枚と100円券8枚 出典
内容・給付
歩行困難な重度心身障がい者にタクシー券を毎月交付（300円券9枚・100円券8枚）し、運賃1割引後の残額支払いに利用できる。身体1・2級、特定3級、愛の手帳1・2度、精神1級の所持者が対象。 出典
申請方法
窓口・郵送・LINEで手続き 出典

公式ページ: https://www.city.shibuya.tokyo.jp/kenko/shogai-seikatsu/waribiki/waribiki.html

この制度について

渋谷区に住む方が対象の福祉タクシー券の交付（給付）です。同じ制度を東京都の他の自治体と比べたい場合は、 渋谷区の制度一覧もあわせてご覧ください。

東京都の他自治体と比べる
  • 東京都で「タクシー・移送・交通費助成」を自治体比較

渋谷区の関連する制度

  • 介護保険サービスの利用手順手続き
  • 介護保険と主な区独自の福祉サービスサービス
  • 住宅設備改修給付助成金
  • ホームヘルプサービス（渋谷区独自サービス）サービス
  • 訪問入浴介護（上乗せ分）サービス
  • 国民健康保険 療養費給付
