渋谷区の渋谷区不妊治療（一般不妊治療・生殖補助医療）医療費助成

渋谷区の不妊・不育治療費等の助成（自治体独自）。一般不妊治療：保険自己負担分を上限5万円まで助成。生殖補助医療：体外受精・顕微授精および併用した先進医療（先進医療は上限15万円）等を助成

制度の内容

対象者
検査・治療開始から申請日まで継続して婚姻または事実婚関係にある夫婦で、夫婦いずれかが渋谷区に住民登録。生殖補助医療は治療開始日の妻の年齢が43歳未満 出典
内容・給付
一般不妊治療：保険自己負担分を上限5万円まで助成。生殖補助医療：体外受精・顕微授精および併用した先進医療（先進医療は上限15万円）等を助成 出典
申請方法
地域保健課地域医療係へ申請（事実婚は申立書・戸籍謄本が必要） 出典
