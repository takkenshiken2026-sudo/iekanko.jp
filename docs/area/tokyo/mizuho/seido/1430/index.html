瑞穂町の介護保険住宅改修費支給制度

瑞穂町では、介護保険により手すり取付けや段差解消などの住宅改修費を支給しています。

最終確認日: 2026-07-10 ／ 対象自治体: 瑞穂町

制度の内容

支給額・助成額
同一住宅で20万円が上限 出典
支給額・助成額
1割負担の場合、20万円の住宅改修で保険給付18万円 出典
条件
新築は対象外 出典

▶ 公式ページ: https://www.town.mizuho.tokyo.jp/kenkofukushi/003/p006167.html

この制度について

瑞穂町に住む方が対象の介護保険住宅改修費支給制度（住まい助成）です。同じ制度を東京都の他の自治体と比べたい場合は、 瑞穂町の制度一覧もあわせてご覧ください。

瑞穂町の関連する制度

  • 高齢者補聴器購入費助成事業助成金
  • 日常生活用具給付事業給付
  • 重度身体障害者（障害児）住宅設備改善費給付事業住まい助成
  • 重度心身障害者（障害児）紙おむつ給付事業給付
  • 高齢者紙おむつ給付事業給付
  • 高齢者自立支援日常生活用具給付事業給付
