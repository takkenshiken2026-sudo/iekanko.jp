神津島村の定住化対策事業交付金

神津島村では、空き家バンクを利用した空き家の改修、除却、伐開に対し、移住・定住推進を目的とした交付金を出しています。

最終確認日: 2026-07-10 ／ 対象自治体: 神津島村

制度の内容

支給額・助成額
原則2分の1。10年以上居住の改修等は3分の2 出典
支給額・助成額
改修上限150万円または200万円、除却100万円、伐開50万円 出典
内容・給付
空き家等の改修、除却、伐開を対象 出典

公式ページ: https://www.vill.kouzushima.tokyo.jp/reiki/reiki_honbun/g159RG00000420.html

この制度について

神津島村に住む方が対象の定住化対策事業交付金（助成金）です。同じ制度を東京都の他の自治体と比べたい場合は、 神津島村の制度一覧もあわせてご覧ください。

東京都の他自治体と比べる
  • 東京都で「耐震・ブロック塀・空き家助成」を自治体比較

神津島村の関連する制度

  • 高齢者住宅改造費助成住まい支援
  • 地域生活支援事業（日常生活用具・住宅改修費）給付
  • 高齢者住宅改造費助成（負担金額減免）税軽減
