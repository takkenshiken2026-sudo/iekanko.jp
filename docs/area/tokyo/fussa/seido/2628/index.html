この制度について

福生市の福生市 住居確保給付金は、離職・廃業（原則2年以内）または休業等により収入が減少し、住居を喪失している・そのおそれのある方。世帯の収入・資産要件、求職活動要件ありを対象とした助成金です。支援内容は、原則3か月間（要件を満たせば3か月ごとに延長し最大9か月）、賃貸住宅の家賃相当額（上限あり）を家主等へ代理納付。上限額は公式ページでご確認くださいです。

申請方法は福生市 社会福祉課 生活福祉係（生活・就労相談窓口／自立相談支援機関）です。

金額・対象・申請方法は制度改定で変わることがあります。最新情報は下記の公式ページや福生市の窓口で必ずご確認ください。
