医療費助成

西東京市の子供医療費助成制度（マル乳・マル子・マル青医療証）

西東京市の子ども医療費助成。保険診療の自己負担分を助成。従来の一部自己負担額200円は撤廃済み。健康診断・予防接種・薬の容器代・差額ベッド代・文書料等の保険外は対象外

制度の内容

対象者
市に住所があり健康保険に加入している、0歳から18歳到達後最初の3月31日までの児童。義務教育就学児=6歳年度末翌日〜15歳年度末、高校生等=15歳年度末翌日〜18歳年度末 出典
内容・給付
保険診療の自己負担分を助成。従来の一部自己負担額200円は撤廃済み。健康診断・予防接種・薬の容器代・差額ベッド代・文書料等の保険外は対象外 出典
申請方法
医療証交付申請が必要。子の医療保険内容がわかるものと、申請者・配偶者・子のマイナンバーがわかるものが必要。申請者は子の父母のいずれか又は生計維持者 出典

公式ページ: https://www.city.nishitokyo.lg.jp/kosodate/teate_zyosei/kodomonoiryouhi.html
