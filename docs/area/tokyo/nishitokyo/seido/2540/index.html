この制度について

西東京市の西東京市高齢者救急代理通報は、高齢や障害、疾病のため緊急事態が生じたときの対応に不安を感じる方を対象としたサービスです。支援内容は、緊急通報機器の貸与により緊急事態を民間の受信センターに通報。自己負担は実費の1割（生活保護受給世帯等は除く）です。

申請方法は高齢者支援課（田無第二庁舎、042-464-1311）です。
