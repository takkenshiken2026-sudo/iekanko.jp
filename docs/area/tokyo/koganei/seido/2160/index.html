小金井市の小金井市奨学資金（奨学金制度）

小金井市の奨学金・進学支援（入学支度金・修学資金等）。給付制（返済不要）。高校生・高専1〜3年：月額5,300円／大学生・高専4〜5年：月額12,200円

最終確認日: 2026-07-23 ／ 対象自治体: 小金井市

※この情報は自動収集した暫定データで、内容確認中です。必ず公式ページでご確認ください。

制度の内容

対象者
基準日の6か月前から市内在住者の子で、高等学校・大学・高等専門学校に在学し、成績優秀ながら経済的事情で修学が困難な方 出典
支給額・助成額
給付（返済不要）。高校生・高専1〜3年 月額5,300円／大学生・高専4〜5年 月額12,200円。原則4月から1年間支給 出典
内容・給付
給付制（返済不要）。高校生・高専1〜3年：月額5,300円／大学生・高専4〜5年：月額12,200円 出典
条件
成績優秀であるにもかかわらず経済的事情により修学が困難と認められる方 出典
申請方法
毎年度奨学生募集。小金井市教育委員会 出典

公式ページ: https://www.city.koganei.lg.jp/kosodatekyoiku/gakkou-kyouiku/syuugakuenjoseido/shogakukinannai.html
