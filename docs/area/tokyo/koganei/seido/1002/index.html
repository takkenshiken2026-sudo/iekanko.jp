小金井市の児童扶養手当

小金井市では、父母の離婚などによりひとり親家庭等となった児童を養育する方に児童扶養手当を支給しています。

最終確認日: 2026-07-09 ／ 対象自治体: 小金井市

制度の内容

対象者
父母の離婚等の児童を養育する方 出典
支給額・助成額
第1子全部支給は月額48,050円 出典
条件
所得制限等あり 出典

▶ 公式ページ: https://www.city.koganei.lg.jp/kosodatekyoiku/N84/kakusyuteate/zidouhuyouteate/jidouhuyouteate.html

この制度について

小金井市に住む方が対象の児童扶養手当（手当）です。同じ制度を東京都の他の自治体と比べたい場合は、 小金井市の制度一覧もあわせてご覧ください。
