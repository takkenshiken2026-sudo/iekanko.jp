小金井市の小金井市 保育料等の第1子無償化・多子世帯軽減

小金井市の保育料軽減（多子世帯軽減・第2子以降無償化・副食費助成等）。第1子の保育料も無償化。多子世帯は第1子の年齢上限撤廃により負担軽減。市独自に給食費（主食費・副食費）への一部補助を拡大（上限額あり）

制度の内容

対象者
認可保育施設等を利用する児童。令和7年9月以降は第1子も無償化の対象。2歳児クラスまでの課税世帯の多子世帯については第1子の年齢上限を撤廃 出典
支給額・助成額
認可・認証等の2歳以下第1子も保育料無償化（保育料0円）／区分別具体額の記載なし 出典
内容・給付
第1子の保育料も無償化。多子世帯は第1子の年齢上限撤廃により負担軽減。市独自に給食費（主食費・副食費）への一部補助を拡大（上限額あり） 出典
条件
認可保育所利用者。多子軽減は同一世帯に幼稚園（認定こども園含む）と認可保育所に在園する子がいる場合、認可保育所の第2子以降を軽減 出典
申請方法
小金井市保育課。詳細は公式ページでご確認ください 出典

公式ページ: https://www.city.koganei.lg.jp/kosodatekyoiku/hoikuen/hoiku-nyuusyo/riyoushahutangaku/all-free.html
