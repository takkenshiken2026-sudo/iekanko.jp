この制度について

小金井市の小金井市高齢者食事支援サービス事業（食の自立支援・配食）は、市内在住65歳以上の在宅で、要支援または要介護認定を受け、日常の買い物や炊事に困難がある方を対象とした助成金です。支援内容は、栄養バランスの整った食事の提供・安否確認を行う配食サービス費用の一部を軽減。費用詳細は公式で確認です。支給額・助成額の目安は配食事業者が700円と設定した場合、市民税課税世帯600円・市民税非課税世帯300円が利用者負担です。主な条件は、食事の確保等が困難なひとり暮らし高齢者等。栄養バランスの整った食事の提供と安否確認、費用の一部を軽減です。

申請方法は介護福祉課高齢福祉係（042-388-8011）です。

金額・対象・申請方法は制度改定で変わることがあります。最新情報は下記の公式ページや小金井市の窓口で必ずご確認ください。
