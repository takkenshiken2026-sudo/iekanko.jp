神奈川県の高齢者紙おむつ支給・助成を自治体で比較

神奈川県33自治体の「高齢者紙おむつ支給・助成」を横断比較しています（掲載 19自治体・各制度に出典/最終確認日つき）。うち18自治体は具体的な支給額・助成額を掲載しています。金額の記載がある自治体を上に表示しています。

この比較からわかること

  • 金額が最も手厚いのは大磯町（月額 40,000円）。
  • 最も少ない海老名市（月額 500円）とは約80.0倍の差があります。
  • 金額を掲載している4自治体の平均は月額 12,750円、上位は大磯町・横浜市・綾瀬市です。
  • 残る43自治体はこの制度が無いか、当サイトで未確認です（ページ下部の一覧に明記）。
