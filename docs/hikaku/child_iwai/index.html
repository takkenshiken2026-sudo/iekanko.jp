東京都の出産・入学祝金/子育てクーポンを自治体で比較

東京都62自治体の「出産・入学祝金/子育てクーポン」を横断比較しています（掲載 50自治体・各制度に出典/最終確認日つき）。うち45自治体は具体的な支給額・助成額を掲載しています。金額の記載がある自治体を上に表示しています。

この比較からわかること

  • 金額が最も手厚いのは御蔵島村（400,000円）。
  • 最も少ない日の出町（10,000円）とは約40.0倍の差があります。
  • 金額を掲載している42自治体の平均は73,206円、上位は御蔵島村・町田市・練馬区です。
  • 残る12自治体はこの制度が無いか、当サイトで未確認です（ページ下部の一覧に明記）。
